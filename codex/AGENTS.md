# AGENTS.md

Global instructions for the Codex CLI, symlinked to `~/.codex/AGENTS.md` by
`codex_merge_config`. Codex reads this on every session, in every project.

This is Codex's equivalent of `~/.claude/CLAUDE.md` — it is currently empty of
real content. Add global preferences here rather than editing `~/.codex/AGENTS.md`
directly, so they stay tracked.
